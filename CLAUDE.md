# CLAUDE.md

Guidance for AI tools working in this repository.

## Handoff Protocol
- Startup: read PROJECT_CONTEXT.md, then DECISIONS.md, then
  WORKING_STANDARDS.md before starting any task.
- Before ending a session or when told to wrap up: commit all
  staged changes with a clear message. If something significant
  happened (a real bug found, a design decision made, a fix
  verified), add an entry to DECISIONS.md following its existing
  format, don't skip this even if it feels minor.
