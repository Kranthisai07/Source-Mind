## 🛠️ How to Use

### Quick Start
```tsx
// Premium Card
<div className="card card-premium card-glow">
  <h3 className="text-gradient">Title</h3>
  <p>Content</p>
</div>

// Premium Button
<button className="btn btn-primary btn-premium">
  Click Me
</button>

// Floating Element
<div className="glass-card animate-float">
  <div className="text-4xl">⚡</div>
  <div className="text-gradient">10x Faster</div>
</div>
```

### Available Classes
- **Glassmorphism**: `.glass`, `.glass-card`, `.card-premium`
- **Gradients**: `.bg-gradient-primary`, `.text-gradient`, `.bg-gradient-mesh`
- **Glow**: `.glow-primary`, `.glow-hover`
- **Animations**: `.animate-float`, `.animate-pulse-glow`, `.animate-bounce-in`
- **Buttons**: `.btn-premium`
- **Blur**: `.backdrop-blur-sm`, `.backdrop-blur-lg`
