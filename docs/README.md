## 🤝 Contributing to Documentation

When adding new documentation:

1. **Choose the right location:**
   - Setup guides → `setup/`
   - Feature guides → `guides/`
   - Project docs → `project/`
   - Development logs → `/logs/` (root level)

2. **Follow naming conventions:**
   - Use `SCREAMING_SNAKE_CASE.md` for official docs
   - Use `kebab-case.md` for guides
   - Use `YYYY-MM-DD.md` for logs

3. **Update this README:**
   - Add your document to the navigation
   - Update the status table
   - Add relevant use cases

4. **Keep it organized:**
   - One topic per document
   - Clear headings and structure
   - Include examples where helpful
