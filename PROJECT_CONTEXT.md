# PROJECT_CONTEXT.md

## Before doing anything, read these in order:
1. `docs/architecture/DECISIONS.md` — every real decision, bug,
   and fix, with reasoning. This is the actual project history,
   not a changelog.
2. `docs/architecture/WORKING_STANDARDS.md` — how this project
   verifies correctness. Read this even if you think you already
   know how to test something.
3. `HANDOFF_SUMMARY.md` (if present) — recent git state, generated
   fresh by handoff.sh, not manually maintained.

## Do not duplicate DECISIONS.md here. If something significant
happens, it goes there, not in a second log.
